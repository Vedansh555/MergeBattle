# Merge Battle - YouTube Playables build

Merge cute pals, cast cards and survive 3-minute monster waves - then beat the boss!

This repository holds the **YouTube Playables** version of Merge Battle (single `index.html`, YouTube Playables SDK).

- `index.html` - the game (upload-ready; also zipped as `merge-battle-youtube.zip`)
- `thumbnails/`, `screenshots/`, `video/` - store media
- `STORE_LISTING.md` - name, description, how to play, category, tags
- `YOUTUBE_PLAYABLES_CHECK.md` - how the build meets the Playables requirements
